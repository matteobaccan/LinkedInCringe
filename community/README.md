# Community

I post cringe arrivati dalla community tramite le
[issue "Manda il tuo cringe"](https://github.com/matteobaccan/LinkedInCringe/issues)
e accettati nel progetto. Un file per post, con livello e moduli assegnati:

```markdown
---
origine: trovato in natura | autoprodotto
livello: 7
moduli: [C02, C21]
issue: #NN
---

<testo del post, anonimizzato>
```

Tutto ciò che entra qui è già passato dalle regole di ingaggio del
[README](../README.md#manda-il-tuo-cringe): anonimizzato, con origine
dichiarata. I pattern che non rientrano nei 33 moduli esistenti sono
candidati a diventare moduli nuovi del catalogo.
